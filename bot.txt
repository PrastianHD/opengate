Telegram Bot OpenGate — Implementation Plan

Context

OpenGate gateway sudah jalan. Sekarang butuh Telegram bot sebagai "toko utama" untuk jual API access. Bot ini jadi frontend pertama yang pembeli pakai — zero friction, langsung di Telegram. QRIS payment skip dulu, simulasi topup dulu.

Database Change

Migration 005_telegram_bot.sql:
- Drop FK users.id → auth.users.id (bot create users langsung tanpa Supabase Auth)
- Add column telegram_id bigint unique
- Add index on telegram_id

Commands

User

- /start — Register + welcome
- /beli — Show 4 packages → tap → simulated payment → balance updated
- /topup — Quick amount buttons → simulated → balance updated
- /cek — Balance IDR + recent usage
- /buat-key — Ask label → generate ogt-xxx → show once
- /hapus — List active keys → tap to revoke
- /key — View masked active keys
- /model — List 4 models with pricing
- /help — Help text

Admin (guarded by role=admin)

- /admin-rekap — Today's transactions summary
- /admin-users — List users with balance
- /admin-revoke — Revoke user's keys
- /admin-topup — Topup user balance

Implementation Steps

1. Migration 005_telegram_bot.sql → run via Supabase
2. bot/lib/supabase.js — standalone client
3. bot/lib/key.js — key generation (copy from gateway)
4. bot/lib/user.js — findOrCreateUser
5. bot/lib/format.js — helpers
6. bot/middleware/auth.js — user lookup
7. bot/index.js — bot init + all commands
8. bot/handlers/*.js — all handlers
9. .env.local — add TELEGRAM_BOT_TOKEN
10. Test locally: node bot/index.js

Verification

2. Send /start → user registered in DB
3. Send /beli → tap package → balance updated
4. Send /buat-key → label → key shown once
5. Send /cek → balance displayed
6. Send /model → 4 models listed
